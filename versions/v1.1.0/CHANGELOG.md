# 更新日志

本文件记录每个版本的变更内容。每个发布版本的安装包、源码包与对应文档快照归档在 `versions/v<版本号>/`。

## v1.1.0（2026-10-19）

### 新增
- **首页**：新增首屏「首页」，聚合展示当日课表、正在上的课/下一节课、今日待办与实时倒计时，并提供备忘/课表快捷入口。
- **课表月视图**：支持按月查看每天课程，点击日期查看当天课程详情；周视图保留。
- **设置与统计合页**：设置与统计合并为底部「设置与统计」一个入口，设置在上、统计在下。
- **统计热力图**：近 12 周日历热力图展示每日活动强度，并新增今日数据、备忘完成率、各天气类型出现次数。
- **版本归档**：新增 `versions/` 目录与 `scripts/build-release.ps1`，每个版本保存 APK、源码包、更新报告与校验和。

### 变更
- **备忘与待办合并**：备忘录与待办合并为「备忘」一个模块，以截止时间区分类型；支持筛选、置顶、完成动画与实时倒计时。
- **统计维度调整**：统计项改为「首页 / 备忘 / 课表 / 天气」使用次数 + 备忘记录数/完成次数 + 各天气类型次数，v1.0.0 的旧统计自动迁移。
- **课表适配 WakeUp**：重写 ICS 解析，兼容 WakeUp 导出的 `TZID`/UTC/浮动时间、`RRULE`/`EXDATE`、折行属性，并自动推导学期起始日。
- **字体修复**：修复课表页字体被局部硬编码覆盖的问题，统一使用主题排版。
- **动画与交互优化**：页面切换、底部导航选中、待办完成、倒计时刷新等交互增加过渡动画。

### 移除
- **悬浮球**：移除悬浮球功能（前台服务、悬浮窗权限、开机自启、设置项与相关代码全部删除）。

### 数据兼容
- 首次启动自动迁移 v1.0.0 的 `memos.json` / `todos.json` → `notes.json`，旧统计 `items` → 新统计维度；迁移失败会保留原文件并降级为空数据，不会崩溃。

## v1.0.0（2026-10-19）

首个版本，包含：

- 备忘录：增删改查、完成标记、本地 JSON 持久化。
- 课表：读取 WakeUp 导出的 ICS 文件，解析并展示课程。
- 天气：Open-Meteo 联网获取，网络异常时降级展示本地缓存。
- 交互统计：记录备忘录/课表/天气/悬浮球/待办使用次数，本地保存。
- 悬浮球：可拖动悬浮按钮，点击唤起主程序，支持开关。
- 待办倒计时：添加待办并设置截止时间，临近截止展示实时倒计时。
- 简约 UI：Compose Material3 单 Activity 架构，深色/浅色主题。
